# Contributing to AI-Doc-Reviewer

Thank you for your interest in improving **AI-Doc-Reviewer**! Community contributions help make automated code reviews and documentation generation faster and more accurate for maintainers everywhere.

## Ways to Contribute

* **Bug Reports:** Open an issue detailing the steps to reproduce, expected behavior, and system environment.
* **Feature Enhancements:** Propose new language parsers, prompt templates, or CI/CD integrations.
* **Documentation:** Improve setup guides, configuration examples, or inline docstrings.

## Development Workflow

1. **Fork the Repository:** Create your own fork of the project on GitHub.
2. **Create a Feature Branch:** Use a descriptive branch name such as **feat/add-rust-parser** or **fix/diff-truncation**.
3. **Follow Code Standards:**
   * Format Python code according to PEP 8 guidelines.
   * Include type hints and clear Google-style docstrings for all new functions.
   * Ensure configuration changes are reflected in **config.yml**.
4. **Submit a Pull Request:** Open a pull request against the **main** branch with a clear summary of your changes.

## Pull Request Checklist

* Code runs locally without syntax or runtime errors.
* All new functions include comprehensive docstrings.
* Dependencies added to **requirements.txt** are pinned to minimum compatible versions.
